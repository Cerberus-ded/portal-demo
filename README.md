# Портал: демо-версия сайта

Демонстрационная версия сайта салона отделочных материалов «Портал» (Димитровград) для показа заказчику.

- `index.html`: главная, `katalog.html`: каталог.
- Заявки, экран менеджера и админка работают, но всё сохраняется только в браузере посетителя (localStorage и IndexedDB) и никуда не отправляется.
- Фотографии взяты с сайтов фабрик и их дилеров временно, до получения разрешений и своих снимков салона. Страницы закрыты от поисковиков.
