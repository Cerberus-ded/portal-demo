# Портал: демо-версия сайта

Демонстрационная версия сайта салона отделочных материалов «Портал» (Димитровград, ул. Гончарова, 11) для показа заказчику.

- `index.html`: главная, `katalog.html`: каталог. В каталоге межкомнатные двери фабрик Лорд, Зодчий, Андора, Хамелеон, Адема, антивандальная серия «Лайн» и входные двери Торекс, квартирные и уличные.
- Заявки, экран менеджера и админка работают, но всё сохраняется только в браузере посетителя (localStorage и IndexedDB) и никуда не отправляется.
- Фотографии взяты с сайтов фабрик временно, до получения разрешений и своих снимков салона. Страницы закрыты от поисковиков.

## Структура

```
index.html, katalog.html   собранные страницы (GitHub Pages, ветка main)
lord/ zodchij/ andora/ chameleon/ adema/ raznye/ torex/
                           пакеты фото дверей по фабрикам (собираются)
x1/seek.json               данные поиска главной (собираются)
photos/                    фото главной
r31/                       исходники страниц: разметка, приложение каталога, реквизиты салона
src31/                     стили и общие скрипты: поиск, калькулятор, админка, cookie, демо-хранилище
web/<фабрика>/*.json       данные коллекций фабрик (сами фото хранятся вне git)
tools/                     сборка, сбор данных фабрик, обработка фото, проверки в браузере
.claude/agents/            агенты Claude Code для работы над сайтом
CLAUDE.md                  как устроен проект и правила работы
```

## Сборка и проверка

```bash
node tools/build31.mjs . _build/site31
python -I tools/build_demo31.py _build/site31 _build/glavnaya31.src.html _build/demo
# перенести в корень: сначала убрать старые пакеты фабрик (папки с covers.json) и поиск,
# иначе пакеты удалённых и переименованных коллекций останутся на сайте и в git; затем скопировать сборку
for d in */; do [ -f "${d}covers.json" ] && rm -r "$d"; done; rm -rf x1
cp -r _build/demo/. .

node tools/mobile37.mjs . shots <папка с node_modules/puppeteer-core> 360,390,414 demo
```

Для сборки нужны исходные фото дверей (`web/<фабрика>/s/`, `l/` и др.), они есть только на компьютере владельца.
Подробности в [CLAUDE.md](CLAUDE.md).

## Как вносить изменения

Через ветку и pull request в `main`. Коммиты по-русски, о том, что изменилось для посетителя.
