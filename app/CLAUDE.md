# app/: сайт «Портала» на SvelteKit

Svelte-версия сайта, из которой вырастет рабочий сайт. Демо в корне репозитория (GitHub Pages) не трогать отсюда.
Как устроено, откуда данные и как запускать: README.md в этой папке. Общие правила проекта: CLAUDE.md в корне.

- Данные и фото не править здесь: их пишет `scripts/import.mjs` из собранной демо-версии, в git они не лежат.
- Цен нет. noindex не снимать без слова владельца (`INDEXING` в `src/lib/site.ts`). Заявки никуда не отправлять без решения владельца (`src/lib/orders.ts`).
- Перед PR: `npm run check` и `npm run build` без ошибок, страницы на 360, 390 и 414 px без прокрутки вбок, `node tools/deslop.mjs` из корня без ошибок (правило в CLAUDE.md в корне).
- Импорты через `#lib/...` с расширением файла (`#lib/text.ts`), `$app/env` вместо `$app/environment`: так в SvelteKit 3.
